# Fonts

The `fonts/` directory contains `Inter-ExtraBold.otf`, `Inter-SemiBold.otf` and `Inter-Medium.otf`. `scripts/render-poster.py` loads these bundled fonts for the Vacancy Poster of the Day so posters render consistently on local machines and GitHub Actions runners.
