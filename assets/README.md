# Fonts

`Inter-ExtraBold.otf`, `Inter-SemiBold.otf` and `Inter-Medium.otf` are used by
`scripts/render-poster.py` for the Vacancy Poster of the Day, so the poster
renders identically on any machine (including GitHub Actions runners).
