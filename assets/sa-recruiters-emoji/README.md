# SA Recruiters original emoji collection

Original, rights-safe community reaction artwork for Tips Chat and future SA Recruiters surfaces.

| File | Suggested use |
|---|---|
| `sa-recruiters-emoji-01-join.png` | Welcome / join the conversation |
| `sa-recruiters-emoji-02-good-luck.png` | Encouragement / good luck |
| `sa-recruiters-emoji-03-interview-win.png` | Interview success / congratulations |
| `sa-recruiters-emoji-04-ask-question.png` | Questions / curiosity |
| `sa-recruiters-emoji-05-applause.png` | Applause / support |

The `web/` directory contains 512×512 optimized PNG and WebP versions for browser use. All assets use transparent backgrounds and are original SA Recruiters artwork; they are not based on SpongeBob, Patrick, or other third-party cartoon characters.
