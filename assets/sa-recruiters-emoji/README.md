# SA Recruiters community reaction artwork

Original, rights-safe artwork for Tips Chat and other SA Recruiters surfaces. The repository retains the optimized 512×512 WebP files used by the website in `web/`:

| File | Suggested use |
|---|---|
| `sa-recruiters-emoji-01-join.webp` | Welcome / join the conversation |
| `sa-recruiters-emoji-02-good-luck.webp` | Encouragement / good luck |
| `sa-recruiters-emoji-03-interview-win.webp` | Interview success / congratulations |
| `sa-recruiters-emoji-04-ask-question.webp` | Questions / curiosity |
| `sa-recruiters-emoji-05-applause.webp` | Applause / support |

The unoptimized PNG exports are intentionally not tracked: the app loads the smaller WebP versions. All images have transparent backgrounds and are original SA Recruiters artwork, not based on third-party cartoon characters.
