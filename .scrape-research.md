|---|---|---|---|

## Implementation notes

The application has dedicated source classification in `app-data.js`, folder grouping in `app-ui.js`, a Cloudflare Worker startup/D1 mirror, and scheduled Node sync scripts under `scripts/` with Supabase upserts. The new source should use `source_type = careers_page` and stable IDs derived from source slug + detail URL.

The current source filter list includes dedicated sources such as `himalayas`, `adzuna`, `government`, `retail`, and `learnerships`; the new source must be added to every equivalent Worker/client list so it does not leak into General Vacancies.

The Cast-A-Way page has no current vacancy records to ingest; avoid invented placeholders.

---

## Safety / operational constraints

Use normal public HTTP GET requests with low concurrency and delays. Parse server-rendered HTML with Cheerio. Store only public job fields needed by vacancies cards. Never submit application forms, referral forms, newsletter forms, or CAPTCHA interactions.
